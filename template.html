Alguma linguagem concentra repositórios com mais estrelas?

Cada caixa reúne os repositórios de uma linguagem. O eixo vertical é logarítmico: a distância entre marcas representa multiplicação, não soma, para que os campeões não esmaguem os demais.

{{GRAFICO_BOXPLOT}}

O que os dados mostram: {{LEITURA_BOXPLOT}}

Como ler um boxplot

  1. A linha dentro da caixa é a mediana: metade dos repositórios fica acima dela, metade abaixo.
  2. A caixa abrange os 50% do meio, do primeiro ao terceiro quartil.
  3. As hastes vão até os valores mais extremos considerados normais.
  4. Os pontinhos são repositórios muito fora do padrão, os campeões de estrelas.

Caixa mais alta = linguagem com repositórios mais estrelados.

Popularidade: estrelas e forks

Estrelas indicam interesse; forks indicam que alguém copiou o projeto para usar ou modificar. Os dois gráficos usam escala logarítmica porque poucos repositórios têm valores enormes.

Como as estrelas se distribuem entre os repositórios?

Cada barra conta quantos repositórios têm o número de estrelas dentro de uma faixa. A escala é logarítmica: as faixas à direita cobrem intervalos cada vez maiores.
